Focus Mode

AI activity classifier

A desktop activity classifier that uses the active window or tab title to distinguish productive and distracting activity.

Overview

Focus Mode classifies active window and tab titles rather than relying on a countdown timer.

The model was trained on more than 25,000 labeled window titles. It uses 1–2 gram TF-IDF features and a LinearSVC classifier to predict productive or distracting activity.

Workflow

  1. 01

    Read the title

    Read the active window or tab title every ten seconds.

  2. 02

    Classify activity

    Transform the title into TF-IDF features and predict its activity class with LinearSVC.

  3. 03

    Detect sustained distraction

    Raise an alert after five minutes of sustained distracting activity.

Engineering

Text features and classification

The training pipeline uses 1–2 gram TF-IDF features with LinearSVC in Scikit-Learn. The dataset contains more than 25,000 labeled window titles.

Local inference

Pickled model artifacts support low-latency inference in the Python activity-monitoring loop.

Limitations

Window titles provide limited context: the same application can be useful or distracting depending on the task. No held-out accuracy score, confusion matrix or measured inference benchmark was supplied for this portfolio.
